# PixelFlow — Unity 6.6

UFO’ların uçak iniş takımlarına binip renkli karelere ateş ettiği üç boyutlu oyun taslağı. Altı bölüm ve kendi bölümünü çizebileceğin alan bulunur.

## İndir ve aç

1. Bu sayfada yeşil **Code → Download ZIP** seç.
2. İnen **PixelFlow-main.zip** dosyasına sağ tıkla, **Tümünü ayıkla** seç.
3. Unity Hub’da **Projects → Add → Add project from disk** seç.
4. Çıkardığın **PixelFlow-main** klasörünün içindeki **PixelFlow-Unity** klasörünü ekle. Doğru klasörün içinde **Assets**, **Packages** ve **ProjectSettings** birlikte bulunur.
5. Unity 6.6 ile aç. Üst menüden **PixelFlow → Oyun sahnesini hazırla** seç.
6. **Game** sekmesine geçip **▶ Play** düğmesine bas.

Kendi bölümünü çizmek için **PixelFlow → Bölüm tasarla** menüsünü kullan.

Daha ayrıntılı anlatım: [İlk açılış kılavuzu](ILK-ACILIS.md).

## Kontrol durumu

Oyun kuralları gerçek C# derleyicisiyle derlenip çalıştırıldı; altı bölüm verilen UFO’larla tamamlandı. Unity kodları yönetilen başvuru dosyalarıyla ayrıca derlendi. Bu bulut ortamında Unity Editörü bulunmadığından ilk Unity 6.6 içe aktarma, görüntü ve Play denemesi yerel editörde yapılmalıdır.
